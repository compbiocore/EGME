# Overview

Notebooks that were used for the EGME tRNA and rRNA analysis are here as well as data for them. We have:

 * `trna.qmd`: Plots of tRNA coverage for tRNAs found by sRNAbench
 * `rsrna.qmd`: Differential expression by FUSION and plots of rsRNA coverage for rsRNAs found by sRNAbench using the RNAcentral database

For each analysis there is also the associated data:

 * `trna_coverage_line_data.csv`: coverage line data for coverage plots for tRNA
 * `rRNA_coverage_line_data.csv`: coverage line data for coverage plots for rRNA
 * `tmp50_0.txt`, `tmp60_0.txt`, `tmp75_0.txt`, `tmpcond.txt`: files required for FUSION differential expression analysis for rsRNAs
